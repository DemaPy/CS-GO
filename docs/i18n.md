# Languages

English and Russian, with no i18n library. This is the pattern this Next.js
version documents: `app/[lang]/`, a `proxy.ts`, and typed dictionaries.

## URLs

| Public URL | Language | Served from |
|---|---|---|
| `/`, `/subscribed` | English | rewritten to `/en/…` (the address bar is unchanged) |
| `/ru`, `/ru/subscribed` | Russian | `/ru/…` |
| `/en/…` | — | 307 to the unprefixed URL (one canonical URL per page) |

## How a language is chosen (`src/i18n/route.ts`, unit-tested)

1. A URL that names a language wins: `/ru…` is always Russian.
2. On an unprefixed URL, the `lang` cookie wins. The EN · RU switch in the
   credits strip writes it.
3. Otherwise the browser's top `Accept-Language` entry decides. The
   Cyrillic-script and post-Soviet set (`ru uk be bg sr mk kk ky uz tg`) gets a
   307 to `/ru…`; everything else, including Polish and the other Latin-script
   Slavic languages, gets English. Redirects keep the full query string, so
   `utm_*` survives.

Redirects are `private, no-store` with `Vary: Accept-Language, Cookie`.

## Copy

Every visible string lives in `src/content/copy/en.ts` and `ru.ts`, typed by
`SiteCopy`. A key missing from one language fails the build. `copy.test.ts`
fails on empty strings, and on a Russian value identical to its English one
unless the key is on its allow-list (the device's own LCD labels).

- **LCD, hybrid.** The DSEG14 segment font has Latin glyphs only. The device's
  own labels (`ADDRESS`, `ARM`, `WAIT`) stay in it in every language. Messages
  in another script (Russian errors, "you're on the list") render in Geist Mono
  via `.readout-mono`.
- **Validation errors** are codes (`src/lib/schema.ts` `EMAIL_ERROR_CODES`),
  translated per dictionary.
- **Email.** The signup's `locale` goes into the capture request and the signed
  confirm token, so the email and the `/subscribed` redirect use the signup
  language. Tokens minted before this change carry no locale and read as
  English.

## Adding a language

1. Add the code to `LOCALES` in `src/i18n/locales.ts` and decide its
   `Accept-Language` mapping there.
2. Add `src/content/copy/<code>.ts` satisfying `SiteCopy`, and register it in
   `src/content/copy/index.ts`.
3. Add the Geist subset for its script in `app/[lang]/layout.tsx` if it isn't
   Latin or Cyrillic.
4. Extend `copy.test.ts` to compare the new dictionary against English.
